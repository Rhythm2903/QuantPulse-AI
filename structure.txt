ARCHITECTURE OVERVIEW:
This is a web application designed for financial education and paper trading. The project is hosted on Vercel using serverless functions for the Python backend.

CONSTRAINTS & RULES FOR AI GENERATION:
1. Backend: The entire backend logic MUST be centralized in a single Python file (`api/index.py`). We are using Flask as the framework.
2. Frontend: We are using a multi-page architecture. Each distinct view (Learn, Trade, Lab, Dashboard) MUST have its own dedicated HTML file located inside the `templates/` directory.
3. Hosting: The project uses Vercel. Do not alter `vercel.json` without explicit instruction.
4. APIs: Market data is fetched from Alpaca's official data API (ALPACA_API_KEY + ALPACA_SECRET_KEY in .env). AI insights use Groq (GROQ_API_KEY in .env). All data fetching happens strictly in the single backend file and is passed to the frontend templates.
